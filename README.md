# Bio-Inspired Lamp Robot 🤖💡

โคมไฟแขนกล 4 แกน ที่มี "อารมณ์" แบบสิ่งมีชีวิต มองคนผ่านกล้อง แล้วตอบสนองด้วยท่าทางและสีไฟ

- **ตา:** กล้อง + MediaPipe ใช้จับใบหน้าและท่ามือ
- **อารมณ์:** ฮอร์โมนเทียม (Artificial Hormone) สะสมและสลายตามเวลา
- **การขยับ:** CPG (SO2 oscillator) สร้างจังหวะการแกว่งตัวที่ดูมีชีวิต
- **ร่างกาย:** แขนกล 4 แกน (Feetech SCS servo) + วงแหวน LED 12 ดวง คุมด้วย Maixduino

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |

## อารมณ์และท่าทาง

| โหมด | เกิดเมื่อ | ท่าทาง | ไฟ |
|---|---|---|---|
| CURIOUS | เห็นหน้า/มือ | ยื่นหัวเข้าไปหาคน หันตาม | เขียว |
| HAPPY | อยู่ด้วยกันนาน / แบมือ | ส่ายตัว ผงกหัว (โบกมือ = ดีใจมากขึ้น) | เหลืองส้ม |
| STARTLED | หน้า/มือพุ่งเข้ามาเร็ว | สะดุ้งดึงตัวขึ้น หงายหัว | ม่วง |
| ANGRY | กำปั้น | ส่ายหัวแรง ๆ โน้มตัวขู่ | แดง |
| SULK (งอน) | โกรธสะสมจนเต็มหลอด | หันหน้าหนี (โบกมือง้อ หรือรอให้หายเอง) | ม่วงแดงหรี่ |
| QUIET (ชู่ว์) | นิ้วชี้แตะปาก | ถอยหลัง → พยักหน้า → เงียบ | น้ำเงินหรี่ |
| EXPLORING / SAD / NORMAL / SLEEPY | ไม่มีใครอยู่ | สำรวจรอบ ๆ → เหงา → หลับ ~9 วิ แล้วตื่นมาสำรวจใหม่ (วนทุก ~17 วิ) | ขาว → ดับ |

**หลอด Mood:** อารมณ์บวกเยอะ แขนจะขยับเร็วและลื่นขึ้น (สูงสุด ×1.5) ส่วนอารมณ์ลบเยอะจะขยับช้าลง (ต่ำสุด ×0.5)

## วิธีติดตั้ง

### ฝั่ง Maixduino
อัปโหลด `maixduino/main.py` ลงบอร์ดด้วย MaixPy IDE (บันทึกเป็น `main.py` บนบอร์ด) ตอนเสียบไฟ LED จะขึ้นเขียว → น้ำเงิน = พร้อมใช้งาน

### ฝั่งคอม (Windows)
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python pc/auto_bio_lamp.py
```
รันครั้งแรกต้องต่อเน็ต โปรแกรมจะดาวน์โหลดไฟล์โมเดล AI มาไว้ในโฟลเดอร์ `pc/models/` ให้เอง

กด `q` หรือปิดหน้าต่างเพื่อปิดโปรแกรม แขนจะค่อย ๆ ก้มลงท่าพักเอง

## ค่าที่ปรับได้ (อยู่ด้านบนของ `pc/auto_bio_lamp.py`)

| ตัวแปร | ความหมาย |
|---|---|
| `COM_PORT` | พอร์ตของ Maixduino เช่น `'COM4'` |
| `CAMERA_INDEX` | `0` = กล้อง laptop, `1` = กล้อง USB |
| `PAN_INVERT` / `TILT_INVERT` | สลับทิศหันซ้าย-ขวา / ก้ม-เงย |
| `STARTUP_Q` / `SHUTDOWN_Q` | ท่าตอนเปิด / ปิด (องศา) |
| `SPEED_MAX_MULT` / `SPEED_MIN_MULT` | ความเร็วสูงสุด/ต่ำสุดตาม mood |
| `SULK_*` | ความไวของหลอดงอน |
| `SMOOTH_GAIN`, `DEADBAND_COUNTS`, `TARGET_DEADZONE`, `SWAY_SCALE` | ลดอาการสั่น |

## ปัญหาที่เจอบ่อย
- **`module 'mediapipe' has no attribute 'solutions'`:** ใช้ `pc/auto_bio_lamp.py` เวอร์ชันล่าสุด ซึ่งใช้ Tasks API แล้ว
- **"รันโหมดจำลอง" / ไม่เจอพอร์ต:** เช็กสาย USB และช่อง USB ของคอม แล้วแก้ `COM_PORT` ให้ตรงกับ Device Manager
- **"Access is denied":** ปิด MaixPy IDE หรือ Serial Monitor ก่อนรัน
